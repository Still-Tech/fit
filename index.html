    Why: latency moves the executed window

    A new plan is based on an earlier observation. Latency decides where execution starts; execution length decides where it ends. This diagram shows the window mechanism.

    A training-free planner

    Method

    Measure a little. Choose how long to execute.

    Q(d, E) = S(d + E) − κ · d · (d + E)

    Input: the synchronous success curve S and one long-window asynchronous run to calibrate the staleness cost κ.

    The planner scores execution windows with Q(d, E) and selects an execution length E(d) for each delay.

    The same calibration gives a latency budget d*: how slow inference can be while keeping the target success rate.
